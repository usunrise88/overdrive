# Overdrive 0.6.0-rc.1

**Это релиз-кандидат (RELEASE CANDIDATE).** Первая сборка нативного приложения-тренера Overdrive для macOS (MacBook на Apple Silicon, macOS 14.0 Sonoma и новее). Приложения для Android не менялись по сравнению с предыдущим RC, но также пересобраны и подписаны тем же релизным ключом. Финальный `v0.6.0` выйдет только после вашей проверки на MacBook и станке.

**This is a RELEASE CANDIDATE.** First build of the native Overdrive ride app for macOS (Apple Silicon MacBooks, macOS 14.0 Sonoma+). The Android apps are unchanged from the previous RC and are rebuilt and signed with the same release key. The final `v0.6.0` comes only after your checks on the MacBook and trainer.

---

## Что нового

- **Приложение-тренер для macOS Apple Silicon (ADR 0044).** Нативное SwiftUI + AppKit приложение `Overdrive.app`, использующее общее ядро Kotlin Multiplatform (`core` → статический `OverdriveCore.xcframework` для `macosArm64`, все 1373 юнит-теста ядра проходят нативно).
- **Стек Bluetooth на CoreBluetooth.** Поддержка умных велотренажёров FTMS, пульсометров Heart Rate Service и контроллера на руль Zwift Click v2 (включая обучение кнопок, фоновое переподключение и запись BLE-логов в `.zip`).
- **Плавающий HUD-оверлей (`NSPanel`) поверх полноэкранного видео.** Компактный и развёрнутый режимы, перетаскивание с прилипанием к краям экрана с учётом выреза MacBook (notch safe area), управление прозрачностью, клик/долгое нажатие, автопоказ при уходе главного окна на задний план.
- **Полный функционал заезда и синхронизации.** Тренировки (`.json`, `.zwo`, план с сервера, свободный заезд и маршруты GPX), ERG/Sim/Slope, виртуальные передачи, защита от падения каденса, Live Coach с озвучкой и приглушением системной громкости, запись crash-safe лога заезда и экспорт FIT, офлайн-очередь отправки на сервер (`outbox`) с хранением токена в macOS Keychain, иконка в menu bar и блокировка сна MacBook во время заезда.

## What is new

- **Native macOS Apple Silicon ride app (ADR 0044).** SwiftUI + AppKit `Overdrive.app` sharing the Kotlin Multiplatform `core` via a static `OverdriveCore.xcframework` (`macosArm64`, all 1,373 core unit tests passing natively).
- **CoreBluetooth BLE stack.** Supports FTMS smart trainers, Heart Rate Service straps, and Zwift Click v2 handlebar controllers (including button learning, background reconnect, and zipped BLE session logs).
- **Floating `NSPanel` HUD overlay over full-screen video.** Compact and detailed modes, drag-and-edge-snap respecting the MacBook notch safe area, opacity control, click/long-press gestures, and automatic display when the main window is hidden behind full-screen video.
- **Full ride and sync workflow.** Workouts (`.json`, `.zwo`, server plan, free ride, and routes), ERG/Sim/Slope modes, virtual gears, cadence stall guard, Live Coach audio cues with system volume ducking, crash-safe ride log recording and FIT export, persistent sync outbox with Keychain bearer token storage, menu bar live power indicator, and MacBook sleep assertion during rides.

## Что попробовать

1. **Первый запуск на MacBook (без notarization):** распакуйте `overdrive-macos-arm64-0.6.0-rc.1.zip`, снимите карантин Gatekeeper командой `xattr -cr Overdrive.app` и откройте `Overdrive.app` (можно перетащить в `/Applications`).
2. **Проверка в режиме симуляции (Simulated Bike):** откройте *Settings → Developer → Device source: Simulated*, запустите встроенную тренировку, разверните полноэкранное видео (например, YouTube) и проверьте появление плавающего HUD-оверлея поверх видео, его перетаскивание и переключение компактного/развёрнутого вида.
3. **Проверка Bluetooth на реальном оборудовании:** переключите источник обратно на *Bluetooth*, выдайте разрешение Bluetooth в системном диалоге macOS, найдите и подключите трейнер FTMS, пульсометр и Zwift Click v2.
4. **Синхронизация с сервером:** введите URL сервера и токен в *Settings → Sync*, проверьте загрузку профиля, плана тренировок и отправку завершённого заезда (включая FIT).

## What you can try

1. **First launch on MacBook (ad-hoc signed, not notarized):** unzip `overdrive-macos-arm64-0.6.0-rc.1.zip`, clear the Gatekeeper quarantine attribute with `xattr -cr Overdrive.app`, and open `Overdrive.app` (optionally move it to `/Applications`).
2. **Simulated Bike check:** open *Settings → Developer → Device source: Simulated*, start a bundled workout, open a full-screen video (e.g. YouTube), and verify the floating HUD overlay appears on top, drags/snaps cleanly, and toggles compact/detailed mode.
3. **Real Bluetooth check:** switch back to *Bluetooth*, grant Bluetooth permission when macOS prompts, and pair/connect your FTMS trainer, HR strap, and Zwift Click v2.
4. **Server sync:** enter your server URL and bearer token in *Settings → Sync*, and verify profile/plan loading and ride + FIT upload after finishing a ride.

## Ещё не проверено на железе

Приложение `Overdrive.app` собрано и прошло автоматические юнит-тесты (`macosArm64Test` + `XCTest`) на Apple Silicon в GitHub Actions, но ещё не запускалось на реальном MacBook:
- реальное подключение по CoreBluetooth к тренажёру FTMS, пульсометру и Zwift Click v2;
- поведение плавающего `NSPanel` поверх полноэкранных Spaces (YouTube/Safari/Chrome);
- управление системной громкостью и медиа-клавишами через macOS Accessibility;
- аудио-подсказки Live Coach и даккинг громкости на динамиках/наушниках MacBook.

## Not tested on hardware yet

`Overdrive.app` has been built and verified by automated unit tests (`macosArm64Test` + `XCTest`) on Apple Silicon in GitHub Actions, but has not yet been run on a physical MacBook:
- live CoreBluetooth connections to an FTMS trainer, HR strap, and Zwift Click v2;
- floating `NSPanel` behavior over full-screen Spaces (YouTube/Safari/Chrome);
- system volume and media-key control via macOS Accessibility;
- Live Coach audio cues and volume ducking on MacBook speakers/headphones.

## Известные проблемы

- **Ad-hoc подпись без notarization:** дистрибуция через Apple Developer ID пока не настроена. После скачивания архива с GitHub macOS поставит флаг карантина — перед первым запуском выполните `xattr -cr Overdrive.app`.
- **Сброс разрешений TCC между ad-hoc сборками:** при замене ad-hoc подписанного `Overdrive.app` на новую сборку macOS может повторно запросить разрешения Bluetooth и Accessibility (при локальной сборке в Xcode с Personal Team в `macos/Config/LocalSigning.xcconfig` разрешения сохраняются).

## Known problems

- **Ad-hoc signed without notarization:** external Apple Developer ID signing and notarization are not configured yet. After downloading the zip from GitHub, clear Gatekeeper quarantine once via `xattr -cr Overdrive.app` before launching.
- **TCC permissions across ad-hoc builds:** replacing an ad-hoc signed `Overdrive.app` may cause macOS to re-prompt for Bluetooth and Accessibility permissions (local Xcode builds with a Personal Team in `macos/Config/LocalSigning.xcconfig` preserve permissions).

## Установка

- **MacBook (Apple Silicon, macOS 14+):** скачайте `overdrive-macos-arm64-0.6.0-rc.1.zip`, распакуйте, выполните `xattr -cr Overdrive.app` и перетащите `Overdrive.app` в `/Applications`.
- **Планшет (Android):** `overdrive-ride-0.6.0-rc.1.apk`.
- **Телефон (Android):** `overdrive-companion-0.6.0-rc.1.apk`.
- Обновление Android поверх предыдущей версии: удалять приложение не нужно, данные сохраняются.

## Installing

- **MacBook (Apple Silicon, macOS 14+):** download `overdrive-macos-arm64-0.6.0-rc.1.zip`, unzip it, run `xattr -cr Overdrive.app`, and drag `Overdrive.app` into `/Applications`.
- **Tablet (Android):** `overdrive-ride-0.6.0-rc.1.apk`.
- **Phone (Android):** `overdrive-companion-0.6.0-rc.1.apk`.
- Updating Android over a previous version: no uninstall is needed, data is kept.
