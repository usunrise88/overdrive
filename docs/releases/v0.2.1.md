# Overdrive 0.2.1

Исправление `v0.2.0` после первой установки на планшет. Меняется только приложение для планшета; серверу обновление не нужно.

Fix for `v0.2.0` after its first install on the tablet. Only the tablet app changes; the server needs no update.

---

## Что нового

- **Приложение называет настоящую причину сетевой ошибки.** В `v0.2.0` любая сетевая неудача выглядела как «Service unreachable»,
  и на первом стенде нельзя было отличить DNS от запрета сети и от таймаута. Теперь в Settings, Sync и в разделе **Planned**
  текст называет причину и в скобках подсказку: «Cannot find the service address (DNS) (UnknownHostException)», «The system
  blocks this app's network access (SocketException · EACCES)», «No network connection», «The service refused the connection»,
  «The connection to the service was cut», «The service did not answer in time». Адрес, IP и токен в подсказку не попадают.
- **Исправлена гонка при запуске списка тренировок.** Если адрес и токен менялись в тот момент, когда приложение ещё читало
  настройки при старте, список «Planned» мог не загрузиться вообще, пока вы не нажмёте обновление (ADR 0017, раздел 2).

## What is new

- **The app names the real cause of a network error.** In `v0.2.0` every network failure read "Service unreachable", and the first
  bench could not tell DNS from a blocked network from a timeout. Settings, Sync and the **Planned** section now say the cause with a
  short hint in brackets, for example "Cannot find the service address (DNS) (UnknownHostException)" or "The system blocks this app's
  network access (SocketException · EACCES)". The address, IP and token never appear in the hint.
- **A race at start-up of the planned list is fixed.** If the address and token changed while the app was still reading its settings
  at start, the **Planned** list could stay empty until you pressed refresh (ADR 0017, section 2).

## Что попробовать

1. Откройте Settings, Sync и **Planned** на экране Ready: при рабочей сети строки «Last upload» и «Updated …» без ошибки.
2. Если «Planned» или «Send now» показывают ошибку, перепишите её слово в слово, вместе со скобками: она называет причину.
3. На планшете, где Chrome открывает сервис, а приложение нет, помогла смена **Private DNS** на `dns.google` (Настройки, Ещё
   подключения, Private DNS): у владельца с `v0.2.0` так и было (`docs/deploy.md`, Troubleshooting).

## What you can try

1. Open Settings, Sync and **Planned** on the Ready screen: on a working network "Last upload" and "Updated …" show no error.
2. If **Planned** or **Send now** shows an error, copy its words exactly, brackets included: it names the cause.
3. On a tablet whose Chrome opens the service while the app cannot, switching **Private DNS** to `dns.google` helped (Settings, More
   connections, Private DNS): it did for the owner on `v0.2.0` (`docs/deploy.md`, Troubleshooting).

## Ещё не проверено на железе

Всё из раздела «не проверено» в `v0.2.0` остаётся в силе (intervals.icu, MCP-клиенты, Google, Telegram, Strava, а также заезд
со снятием показаний на велосипеде). Новое поведение (названия причин) проверено автоматически; какие подсказки (`errno`) выдаёт
именно эта версия Android на этом планшете, покажет первая реальная сетевая ошибка.

## Not tested on hardware yet

Everything listed as untested in `v0.2.0` still stands (intervals.icu, MCP clients, Google, Telegram, Strava, and a full ride with
readings on the bike). The new wording is tested automatically; which `errno` hints this Android version produces on this tablet
will show on the first real network error.

## Известные проблемы

- Всё, что известно по `v0.2.0` (`docs/releases/v0.2.0.md`), остаётся: Click не выбирает плановую тренировку на экране Ready,
  разрешён обычный `http://` для стенда, блокировка MCP-входа общая.
- Telegram: сообщение без переносов строк из описания и без картинки тренировки (OVD-1, OVD-2).

## Known problems

- What is known for `v0.2.0` (`docs/releases/v0.2.0.md`) still stands: the Click cannot choose a planned workout on the Ready screen,
  plain `http://` is allowed for a bench, the MCP sign-in lockout is global.
- Telegram: the message lacks the description's line breaks and a workout picture (OVD-1, OVD-2).
