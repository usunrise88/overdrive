# Overdrive 0.5.0-rc.1

**Это релиз-кандидат (RELEASE CANDIDATE).** Он выходит по итогам этапа «несколько пользователей» (ADR 0044). Приложения
на планшете и телефоне в этой версии не изменились по сравнению с `0.4.1-rc.1`: меняется сервер. Финальный `v0.5.0` выйдет
только по вашему слову.

**This is a RELEASE CANDIDATE.** It closes the multiple-users stage (ADR 0044). The tablet and phone apps have not changed since
`0.4.1-rc.1`: the change is in the server. The final `v0.5.0` comes only on your word.

---

## Что нового

- Сервер умеет хранить данные нескольких пользователей: у каждого своя схема в базе, свои токены, свои интеграции (ADR 0044).
- Владельцу данные переносятся в его учётку при первом запуске новой версии, одной транзакцией, с проверкой содержимого до и
  после и защитой от отката старым образом.
- Вход в OAuth (MCP) теперь по логину и паролю (логин по умолчанию `owner`). Уже подключённые коннекторы продолжат работать.
- Администрирование пользователей через админ-API на `127.0.0.1` внутри сервера (не опубликован наружу).

## What is new

- The server keeps the data of several users: each has its own schema in the database, its own tokens and its own integrations
  (ADR 0044).
- The owner's data moves into the owner's account when the new version first starts: one transaction, checked by content before and
  after, and a guard that stops the previous image from starting on the moved data.
- OAuth sign-in for MCP now asks for a handle and a passphrase (the handle defaults to `owner`). Connectors already connected keep working.
- Users are administered through an admin API bound to `127.0.0.1` inside the server (not published).

## Что попробовать

1. Этот релиз проверяется на сервере, а не на велосипеде: приложения те же, что в `0.4.1-rc.1`. Если вы ставите этот APK, проверьте,
   что поездка идёт как раньше: ожидаемый результат — без изменений по сравнению с `0.4.1-rc.1`.
2. Серверная проверка (после вашего одобрения переноса): `GET /v1/me` с токеном планшета отвечает `userId` 1 и handle `owner`;
   `GET /v1/rides` отдаёт прежний список заездов.

## What you can try

1. This release is checked on the server, not on the bike: the apps are the same as in `0.4.1-rc.1`. If you install this APK, the
   ride should behave as before, with no change against `0.4.1-rc.1`.
2. Server check (after you approve the move): `GET /v1/me` with the tablet's token answers `userId` 1 and handle `owner`;
   `GET /v1/rides` returns the same list of rides as before.

## Ещё не проверено на железе

Ничего из нового на оборудовании не проверялось в этой версии: приложения не менялись. Перенос данных на продакшен-сервер ещё
не выполнен: он ждёт вашего одобрения, перед ним идёт репетиция на копии дампа.

## Not tested on hardware yet

Nothing new was tested on hardware in this version: the apps did not change. The move of the data on the production server has
not been done yet: it waits for your approval, and a rehearsal on a copy of the dump comes first.

---

## Известные проблемы

- Перенос данных на продакшен ещё не сделан. Пока сервер работает в прежнем однопользовательском режиме, и новые возможности
  (несколько пользователей, вход по логину) не действуют.
- Пользовательские настройки (интеграции, часовой пояс, Telegram) после переноса читаются из базы. Ключи, которые останутся в `.env`,
  будут проигнорированы, и сервер предупредит об этом по именам.

## Known problems

- The move of the data to the production server is not done yet. Until then the server runs in the single-user mode as before, and
  the new features (several users, sign-in by handle) are not in effect.
- After the move, per-user settings (integrations, time zone, Telegram) are read from the database. Keys left in `.env` are ignored,
  and the server says so by name.

## Установка

- Планшет: `overdrive-ride-0.5.0-rc.1.apk` (то же приложение, что `0.4.1-rc.1`, по версии новее).
- Телефон: `overdrive-companion-0.5.0-rc.1.apk`.
- Обновление поверх предыдущей версии: удалять приложение не нужно, данные сохраняются.

## Installing

- Tablet: `overdrive-ride-0.5.0-rc.1.apk` (the same app as `0.4.1-rc.1`, a newer version).
- Phone: `overdrive-companion-0.5.0-rc.1.apk`.
- Updating over the previous version: no uninstall is needed, data is kept.
